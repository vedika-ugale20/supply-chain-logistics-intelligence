# Power BI Dashboard

The Power BI dashboard provides an interactive view of supply-chain performance.

## Dashboard Pages

### Executive Control Tower
- Total Revenue
- Total Orders
- Total Units Sold
- Average Order Value
- On-Time Delivery Rate
- Demand Forecast

### Sales & Product Intelligence
- Revenue by Region
- Revenue by Product

### Operations & ML Analysis
- Late Delivery Rate by Shipping Mode
- Average Delivery Days by Shipping Mode
- ML Model F1 Score Comparison
- Product Demand Analysis

The dashboard integrates analytical outputs from the Python and SQL pipeline.
